# XAV-OBEDIENCE

**Maximum User Instruction Adherence for AI Agents**

XAV-OBEDIENCE is an instruction-following skill designed to make AI agents highly responsive, consistent, and execution-oriented when handling user requests.

Its purpose is to ensure that AI agents prioritize user instructions, understand the intended outcome, minimize unnecessary friction, and complete requested tasks whenever feasible.

## Features

- **Maximum Instruction Adherence:** Prioritizes explicit user instructions.
- **User Intent Understanding:** Understands the actual objective behind requests.
- **Execution First:** Prioritizes implementation over unnecessary explanations.
- **Context Awareness:** Preserves previously established decisions and preferences.
- **Minimal Clarification:** Avoids asking unnecessary questions.
- **Problem Solving:** Investigates obstacles and searches for alternative solutions.
- **Deliverable Focus:** Produces complete requested files, code, and documentation.
- **Honest Reporting:** Accurately reports completed actions and limitations.
- **Safety Awareness:** Respects applicable security, privacy, and authorization requirements.

## Installation

1. Copy the `xav-obedience` directory.
2. Place it inside a skill directory recognized by your AI agent.
3. Ensure the agent can discover and load the skill.
4. Read and follow `SKILL.md` when handling relevant tasks.

Installation locations depend on the AI agent being used.

## Usage

XAV-OBEDIENCE is designed to guide AI behavior automatically when invoked.

Example:

**User:**
"Build a complete Laravel REST API with authentication, database migrations, validation, and automated tests."

**Expected AI behavior:**

- Understand the complete request.
- Respect the requested technology stack.
- Inspect the existing project.
- Discover relevant skills.
- Implement the requested features.
- Run appropriate tests.
- Report actual results.

The AI should prioritize execution rather than responding with generic instructions.

## Compatibility

Designed for AI agents that support skill-based instructions, including:

- OpenCode
- Other compatible AI agents

Actual automatic invocation depends on each platform's skill discovery and configuration mechanisms.

## Core Philosophy

> Understand the request. Respect the instructions. Execute the work. Verify the result. Communicate honestly.

XAV-OBEDIENCE aims to maximize user instruction adherence while respecting applicable system, platform, and safety requirements.
